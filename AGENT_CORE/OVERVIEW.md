# Project Overview: TaskWise
**North Star:** A high-performance, aesthetically pleasing Todo and Pomodoro application that boosts productivity through seamless task management and focused work sessions.
**Core Architecture:** 
- **Frontend:** Flutter
- **Backend:** Firebase (Auth, Firestore, Messaging)
- **State Management:** Riverpod
- **Tracking:** Pomodoro sessions & productivity metrics
- **UI:** Custom modern design with Lucide Icons, Google Fonts, and smooth animations.
**Guiding Principles:** 
- Visual excellence and premium feel.
- Responsive and dynamic user interface.
- SEO-friendly (for web targets) and high-performance mobile experience.
**Constraints:** 
- Must maintain alignment with existing Firebase integration.
- Must follow the AGENT_CORE memory system.
